科研项目

Mosaic: Unlocking Long-Context Inference for Diffusion LLMs via Global Memory Planning and Dynamic Peak Taming. Liang Zheng, et al. ICML 2026 CCF-A 面向扩散语言模型（dLLM）的长上下文推理场景，现有推理系统以 KV Cache 为核心的内存管理无法适用于 dLLM。我们发现 dLLM 的内存瓶颈从 KV Cache 转移至瞬态激活值，且内存峰值在 logits 与 FFN 之间随 mask ratio 动态切换；现有框架的局部静态内存规划导致严重碎片化，预留内存超出理论峰值达 43%-78%。因此，我们提出 Mosaic，一个面向 dLLM 的内存高效推理系统，核心贡献包含针对动态峰值的自适应切分策略、基于虚拟寻址的统一激活张量内存池以消除碎片，以及针对 dLLM 的 mask-only logits 高效算子。在相同硬件下，最大可支持上下文长度提升 15.89-32.98×，内存峰均比降低 2.71×，端到端时延降低 4.12%-23.26%。
ViDA: Lossless VideoQA Acceleration via Selective Sparse Self-Speculation With Parallel Computational Load Management. Liang Zheng, et al. IEEE TPDS 2026 CCF-A 现有的多模态大模型通常存在较长的视觉上下文，特别是在视频大模型中，极大拉高了 decode 时延。然而，现有两类方案各有局限：KV Cache 稀疏方法通常有损，投机推理方法大部分需要训练 drafter，在多模态 LLM 中难以获取且泛化性差。因此，我们提出了针对视频大模型的稀疏自投机范式，利用长视觉上下文的稀疏性进行投机推理。围绕选取哪些 token 与选取多少 token 两个核心问题展开研究，提出了多模态感知的 token 选取与自适应动态稀疏 budget 方案。推理时延降低 20%+，精度无损，且 training-free，即插即用。
移动端大模型 Agent 高效推理框架 在研 随着 LLM 能力持续增强与 Agent 框架的迭代演进，端侧 Agent 部署需求日益增长。然而，移动端有限的算力与内存使得 Agent 推理面临高时延与资源瓶颈。针对上述挑战，拟研究面向移动端异构算力（CPU/GPU/NPU）的高效协同调度策略，深入移动端系统架构，针对不同 IP 模块特性与系统层级设计协同调度方案，以实现低时延、资源友好的端侧 Agent 推理。
低精度预训练系统 在研 随着 LLM 参数规模持续增长，参数量与内存 I/O 逐渐成为训练与推理的核心瓶颈，原生低精度预训练为降低训练与推理成本提供了一条有效路径。然而，现有低精度预训练方案探索尚浅，难以在精度保持与训练加速间取得良好平衡。针对这一方向，拟在国产昇腾集群上开展大规模低精度预训练研究，围绕 MXFP8/MXFP4 格式设计高效训练策略，在保证精度的前提下提升训练吞吐。
